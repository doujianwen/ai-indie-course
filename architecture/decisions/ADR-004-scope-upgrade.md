# ADR-004 课程 V1 范围升级：内容策划 + SEO/GEO 运营 + 防跑偏机制提前至 V1

- 状态：已采纳（Accepted）
- 日期：2026-08-11
- 提出：主理人拍板（基于旧版 `ai-independent-dev` 对比与 bookconv 真实素材盘点）

---

## 背景（Context）

课程原 PRD v1.1 把 V1 收敛为 M1–M7（self-serve，不含陪跑），内容策划 / 运营推广 / 防跑偏均放在 v2。主理人在对比旧版课程 `ai-independent-dev` 后提出两点意见：

1. 本课程**不止覆盖开发**，还应包括**内容策划 + 运营推广**环节——这是「从想法到有人用」的最后一段，竞品全缺。
2. bookconv.com 已经跑通**不错的 SEO 与 GEO 实践与数据**，应作为课程核心素材**充分利用**，而非另起炉灶编造。

旧版 `ai-independent-dev` 里有两个值得借的「对的范围」：
- 它覆盖完整生命周期（含 SEO 营销、变现、运营），比本版原 v1 更完整；
- 它有 `correction-agent`「纯纠错型智能体」概念（角色固化、一票否决、纠察组与方案组信息隔离），正好对应本版 PRD §2 画像 A 已识别的「外部约束 + 第三视角」核心需求。

但旧版有「错的实质」：虚构讲师张三、虚构案例 WriteAI、占位数据。本版不借内容，只借**结构**与**机制**。

---

## 决策（Decision）

V1 范围升级（v1.2），三项调整：

1. **内容策划 + 运营推广从 v2 提升至 v1 主线**
   - 新增 **M8 内容策划系统**（一页吃整簇 + 单源内容注册 + 内链架构），RICE 6.4
   - 新增 **M9 SEO/GEO 运营增长**（sitemap/llms.txt/robots/hreflang + GSC/GA4 实战 + 外链策略），RICE 6.4
   - 与既有 M4 增长诊断共同覆盖「上线后怎么拿到第一批用户」全链路。

2. **借旧版 correction-agent 概念，落地 M10 防跑偏 / 第三视角纠错机制**
   - RICE 7.2（画像 A 占预期学员 60–65%，几乎人人需要）
   - 机制：范围冻结清单 + 阶段验收关卡 + 纠错清单（phase0 需求验证 / phase1 MVP 形态 / phase2 营销转化 / phase3 规模化）
   - 不照搬「多智能体协作」外壳，只取「外部约束 / 一票否决 / 信息隔离」内核，落成为课程内建机制与清单。

3. **bookconv 的 SEO/GEO 真实实践与数据作为核心素材（不编造）**
   - 87 页内容体系（36 博客 + 21 指南 + 30 转换页）
   - 「一页吃整簇」长尾内容策略（`docs/content/一页吃整簇策略.md`）
   - 185 条编辑内链架构（通用锚文本 0 条）
   - `llms.txt` + `robots.txt` 放行 GPTBot/ClaudeBot/CCBot 的 GEO 实践
   - GSC/GA4 真实复盘数据（287 展示 / 0 点击，选择性披露 + 截图脱敏）
   - 内页外链策略（素材回流仓库）

原 v2 模块顺延重编号：M11 付费闭环 / M12 生产可观测 / M13 异步任务队列 / M14 30 天陪跑 Sprint（defer v2 不变）。

---

## 后果（Consequences）

**正向**
- V1 真正覆盖「从想法到有人用」的完整生命周期，差异化护城河从「开发 + 诊断」扩到「开发 + 内容 + 增长 + 防跑偏」。
- 用 bookconv 真实资产教学，规避了旧版「虚构案例 / 占位数据」的诚信风险，也直接复用已沉淀的 SEO/GEO 作战记录。
- 防跑偏机制正面回应画像 A「没有第三视角」的核心痛点，强化 self-serve 课程也能提供「外部约束」的稀缺价值。

**负向 / 风险**
- V1 录制体量从约 20 节升至约 23 节（新增 18/19/20 三章 + G1 不变），首期制作成本与排期上升。
- M8/M9 依赖 bookconv 真实数据的可教学性——需确保演示用数据已脱敏且可复现（沿用 §8 边界条件与 G1 截图脱敏口径）。
- 防跑偏机制若做成「又一套智能体工具」会偏离本质，必须克制为「清单 + 关卡」的轻量机制，不引入额外运行时代码。

**对齐**
- PRD v1.2 §0 判断四、§4 支点 6、§5 RICE（M8–M14）、§7 AC-7、§12 v1.2 收口项
- `01-tech-outline.md` Phase 7（第 18–20 章）
- `06-curriculum-spec.md` 模块↔章节映射、章节明细、V1 范围边界
- `README.md` 关键决策记录 #7
