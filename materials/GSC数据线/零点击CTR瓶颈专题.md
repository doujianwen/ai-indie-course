> 课程模块：**M9 SEO/GEO 运营增长** · 子主题「从曝光到点击的断裂」

## 一、一句话结论（课程开场白可用）

> 250 个词上了排名、累计 **1266 次展示、0 次点击、CTR 0%**。
> Google 已经愿意把页面摆到用户面前，但**没人点**。这不是"词不够"，是" snippet 不吸点击 + 排名不够靠前"。这是新站 SEO 第一阶段结束、第二阶段开始的分水岭信号。

## 三、真实案例：排名进首页却 0 点击 ⭐

最关键的反直觉证据——**有词排在 Google 第 1 页（位置 8–10）依然 0 点击**：

| 查询 | 位置（8/14 拉取） | 展示（窗口累计） | 点击 | 说明 |
|---|---:|---:|---:|---|
| `mobi vs azw3` | **#8.31** | 17 | 0 | 第 1 页、折叠边缘，0 点击 |
| `azw3 vs mobi` | **#10.24** | 33 | 0 | 第 1 页底部，0 点击 |

- 这两个词是「对比类」高意图词，本该是点击率最高的池子（用户在做购买/格式决策），却整段 0 点击。
- 教学：位置 8–10 是"首页但折叠下沿"，CTR 天然低；加上 **title/描述未优化**，用户划过不点。这正是"排名好、点击差"的典型，比"排名差"更难被发现——因为看排名报表会觉得"已经第 8 了，没问题"。

## 五、根因（诚实拆解，不甩锅给算法）

1. **标题/描述未优化**：默认 title 模板 + 未写 compelling meta description，SERP 里和 big site 比毫无点击诱因。
2. **富结果未渲染**：FAQ / HowTo JSON-LD 已上线但 Google **未渲染**成富结果（Sitelink/FAQ 折叠），失去额外版面与点击诱因。
3. **位置 8–10 的折叠效应**：即使上了首页，下沿位置 CTR 远低于 1–3；需外链把词往前推。
4. **意图错配**：部分展示词（如 `azw3` 单字）是泛词，用户未必想转换，点了也白点——但 0 点击说明连"误点"都没有，主因仍是 1、2。

## 六、杠杆切换：从"加词"到"CTR + 外链"

| 阶段 | 驱动动作 | 瓶颈信号 |
|---|---|---|
| 第一阶段（0→200 词） | 发内容铺量 → 涨词+涨展示 | 已完成（250 词、1266 展示） |
| **第二阶段（现在）** | **攻标题/描述 CTR + 富结果 + 外链提排名** | **卡在 0 点击** |

- 教学：继续堆词的边际收益骤降——新词多半排 40–80 名，本就带不来点击。**先把已展示池的 CTR 做起来**，再让外链把排名前移，才是正循环。
