## 来源与边界（诚实账本）
- 以上素材由主站工作区的 `.workbuddy/memory/` 每日日志结构化提炼而来。
- **原始每日日志（`2026-MM-DD.md` ×19 + 缺失日还原）留在主站仓库的 `.workbuddy/memory/`**（被 gitignore，不进任何仓）**，本目录只收提炼后的素材，不收原始 19 篇日志**，避免课程仓膨胀。
- 数字均取自真实日志 / GSC / GA4，未编造；样本小（如 GA 仅 29 用户）时文档已明确标注"只当方向"。
- 素材中文撰写（内部源）；英文版为本地化目标，按 ADR-005 执行。
